========================================================================
 通知发送器 dsh-notify-sender  v0.3.0  安装说明（三步）
========================================================================

【这是什么】
借用本机 DSH 已经接通的通道，把一条通知发到你勾选的那几个账号。
它自己不建立任何连接、不接收消息、不存凭据 —— 只是「挑账号 + 发一条」。
依赖同作者的「推送中枢」(dsh-push-hub) 作为发送底座。

【第 0 步：确认你在用哪个 profile（必须，最容易踩的坑）】
DSH 的不同 profile 是彼此独立的目录。装错 profile 的表现是：
插件文件都在、界面却永远看不到入口、/api/info 永远 404。

PowerShell 里查当前运行的实例指向哪个 profile：

    Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
      Select-Object ProcessId, CommandLine |
      Where-Object { $_.CommandLine -like '*dsh*' }

输出里出现 \.dsh\profiles\desktop\ 就用 desktop，
出现 \profiles\web\ 就用 web。下面所有路径里的 <profile> 都换成它。

【第 1 步：把包放进本机并登记到 profile】
假设你把本包解压/克隆到了 <插件根目录>\dsh-notify-sender。

编辑 <用户目录>\.dsh\profiles\<profile>\package.json，两处都要加：

    "dependencies": {
      "@duma520/dsh-notify-sender": "link:<插件根目录>/dsh-notify-sender"
    },
    "dsh": {
      "profile": {
        "bundles": [
          "@duma520/dsh-notify-sender"
        ]
      }
    }

【第 2 步：建 node_modules 链接（Windows 用 junction，不需要管理员）】

    New-Item -ItemType Junction `
      -Path   "<用户目录>\.dsh\profiles\<profile>\node_modules\@duma520\dsh-notify-sender" `
      -Target "<插件根目录>\dsh-notify-sender"

【第 3 步：重启 DSH，然后三处验证】
A. 侧栏能看到信封图标 ✉（悬停提示「通知发送器」）。
   看不到就看侧栏「插件」下拉菜单的「更多」里有没有一行「✉ 通知发送器 只发不收」。

B. 点进去，顶部应显示「只发不收」标签与「可用账号 N / M」计数。
   N=0 说明推送中枢没装或没配通，先修它。

C. 随便发一条测试通知，手机/群里真收到，就算通了。

========================================================================
配置与数据在哪
========================================================================
- 配置文件：<用户目录>\.dsh\dsh-notify-sender\config.json
  （界面改动实时自动落盘，不需要手动保存）
- 发送记录：同目录的 history.json（只存摘要，不存正文全文）
- 它读别的插件的配置来聚合账号，自己不存任何凭据：
  推送中枢    <用户目录>\.dsh\dsh-push-hub\config.json
  IM 桥接     <用户目录>\.dsh\dsh-bridge\config.json
  IM 连接     <用户目录>\.dsh\dsh-im-connect\channels.json
- 环境变量 DSH_NOTIFY_SENDER_DIR 可改数据目录（回归测试靠它隔离）。

【卸载】
1. 从 package.json 的 dependencies 与 dsh.profile.bundles 里删掉 @duma520/dsh-notify-sender；
2. 删掉 node_modules\@duma520\dsh-notify-sender 这个 junction；
4. 数据目录：<用户目录>\.dsh\dsh-notify-sender\（config.json / history.json）
3. 重启 DSH。

【开源仓库说明】
本包只含插件本体。作者本机的 scaffold/（开发探针与回归脚本）与
version/（历次备份快照）不在仓库里，因为它们绑定本机路径与本机真实数据。
README 里凡出现 node scaffold/... 的命令，clone 仓库后都跑不了，属正常。
